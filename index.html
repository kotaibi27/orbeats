Who it is for

Science data should not need eyes.

NASA's Earth data is mostly shown as pictures. Turning it into sound opens it to people who cannot see the picture, and it makes every visitor listen more closely.

Audio-first mode

A simplified, voice-guided layout with one control at a time.

Start audio-first mode
  1. Put on headphones or use the speaker. [Kiosk headphone location placeholder]
  2. Press Tab until you hear “Audio-first mode”, then press Enter.
  3. The voice guide reads each choice. Space plays or pauses, N moves to the next track.
  4. Press Escape at any time to return to this screen.
